01 / DATA

准备测试数据

测量和背景分行记录；测量保留 PRV 来源和条件，背景包含起止及实际到达时间。可直接编辑所有字段。

0 条记录

时间请使用带 Z 或偏移量的 ISO 格式；时区使用 IANA 名称（如 Europe/Stockholm）。空白代表未知。删除仅影响此页面副本。

字段与示例格式

type 为 measurement 或 context。modality 标识 PPG 或 ECG；source 标识背景来源。time 为测量时间或背景结束时间；start 为背景开始时间；arrival 为可用时间。sleep 单位小时，activity 单位步数，rhr 单位 bpm，energy、fatigue 为 1–5，work：1 是工作、0 不是；diet：用户明确记录的饮食背景，1 有、0 无。设备与算法必须准确标识，quality 默认 good。

02 / SETTINGS

定义你的实验

背景系数默认为零；测量来源或质量不符合条件时不会被混用。所有门槛是可修改的工程设置。

背景特征与模型系数

自动参考为历史背景的每日均值；手动参考留空时使用自动值。启用特征后，如果当前值或参考缺失，模型会降级。

系数来源：默认假设
可选：月经周期与 HRV

仅在你主动记录时使用。自然周期的已知卵泡阶段记为 cycleLuteal=0，黄体阶段记为 1；cycleStatus=natural，cycleMethod 为 self_report、calendar、LH 或 hormone，cycleId 为本次周期标识。未知阶段留空；日历估计保留为估计，不自动判断排卵。激素避孕、妊娠、围绝经及未知状态不套用自然周期系数。

启用后使用预测当时已知的阶段，作为滞后背景特征，并不预测目标日阶段。系数默认零，可手动调整或个人拟合。研究平均差异不等于你的变化；每阶段至少 5 天、至少 2 个周期仅是可调工程门槛。回测额外比较“移除周期特征”，检验是否真正改善预测。不会仅因周期阶段改变生活建议。

证据与方法边界

页面实现连续时间衰减自回归实验模型，而非已验证的分层世界模型；默认系数不是文献效应量。预测区间来自此前的样本外残差，不保证覆盖率。主动测量与测量误差可能影响结果；合成数据不能证明有效性。
